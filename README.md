## Projeto em destaque

### Consulta de Manifestação NF-e

Aplicação Web voltada para **consulta de eventos de NF-e, geração de relatórios em Excel e sincronização controlada de dados fiscais**.

**Tecnologias:** Python, FastAPI, SQLite / SQLCipher, HTML, CSS e JavaScript.

**Foco do projeto:**

- reduzir consultas e conferências manuais;
- organizar dados fiscais em uma interface simples;
- gerar relatórios de forma prática;
- manter segurança e rastreabilidade nas operações.
